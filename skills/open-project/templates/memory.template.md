## §J 格式規則

3. 每條必填：症狀／根因／解法／現況／出處。
4. 未驗證一律入 §D，唔准寫入 §A／§G「已修」。
5. 每次 session 收工：新坑入 §B／§G，狀態入 `project_status.md`。
6. 狀態欄 current／superseded／revoked 必填；「而家應該信邊條」永远以 current 鏈最新為準。
